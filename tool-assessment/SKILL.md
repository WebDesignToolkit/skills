# Open-source tool assessment

1. Identify source repository, owner and current release.
2. Read authoritative README, LICENSE, changelog and security policy.
3. Note licensing uncertainties, maintenance, dependencies and install permissions.
4. Classify the project's relevance using catalog taxonomy.
5. Do not execute untrusted code, request credentials, or scrape behind logins.
6. Compare at least one alternative and distinguish observed behavior from README claims.
7. Propose catalog candidate changes, never mark reviewed solely on metadata.
