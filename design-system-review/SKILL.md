# Design-system review

Read the project's actual design rules first. Enumerate tokens, type scales, grids, spacing, surfaces, component states and breakpoint decisions. Compare implementations across representative pages. Specifically verify hover, focus-visible, active/pressed and disabled states. Record mismatches with concrete file paths and reproduction instructions. Do not redesign components without user approval. Generate a ranked remediation plan and identify reusable primitives.
